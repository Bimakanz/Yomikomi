# UI/UX Redesign: Transform Yomikomi into a Unified "Manga + Anime" Dual-Mode Platform

Saya ingin merombak desain layout Yomikomi agar mendukung 2 mode utama: **Baca Komik (Manga/Manhwa)** dan **Nonton Anime**, tanpa membuat tampilan berantakan.

Tolong perbarui layout Navbar, HomePage, MangaCard, DetailPage, dan tambahkan struktur halaman Anime dengan spesifikasi desain berikut:

## 1. Top Navbar: Global Mode Switcher (`📖 Komik` | `🎬 Anime`)
- Tambahkan komponen **Segmented Pill Switcher** tepat di sebelah kanan logo `Yomikomi` dengan 2 pilihan:
  - `📖 Komik` (Tema aksen utama: Oranye `#FF6B00`)
  - `🎬 Anime` (Tema aksen utama: Ungu/Indigo `#8B5CF6` atau aksen sinema yang elegan)
- Simpan mode aktif (`activeMediaMode: 'manga' | 'anime'`) di dalam global state.
- Ubah teks menu `Riwayat Baca` menjadi `Riwayat` (di dalamnya memiliki tab terpisah untuk Riwayat Komik & Riwayat Anime).
- Ubah placeholder search bar menjadi `Cari komik atau anime... (Ctrl+K)` yang dapat mencari sesuai mode aktif atau menampilkan tab hasil Komik & Anime sekaligus.

## 2. Baris "Lanjutkan Baca / Nonton" (Continue Row) di HomePage
- Tepat di bawah Hero Banner (sebelum barisan filter), tambahkan section horizontal **"▶️ Lanjutkan"** (hanya tampil jika user memiliki riwayat di localStorage/IndexedDB).
- Tampilkan maksimal 4 kartu horizontal ringkas berisi: Cover kecil, Judul, Chapter/Episode terakhir yang dibuka, progress bar visual, dan tombol klik langsung menuju Reader/Player.

## 3. Dynamic Filter Bar & Upgraded Media Cards
- Saat mode `📖 Komik` aktif: Tampilkan filter `Semua Komik`, `Paling Populer`, `Baru Diupdate`, `ID Indo Scan`, `GB English`, dan `Filter Genre`.
- Saat mode `🎬 Anime` aktif: Ubah filter secara dinamis menjadi `Semua Anime`, `Sedang Tayang (Seasonal)`, `Paling Populer`, `Sub Indo`, `Movie`, dan `Filter Genre`.
- **Upgrade Desain Kartu (MangaCard / AnimeCard):**
  - Pojok kiri atas: Badge Status (`ONGOING`, `COMPLETED`).
  - Pojok kanan atas: Badge Rating (`⭐ 8.4`) jika tersedia.
  - Pojok bawah cover (dengan background gradient gelap): Badge Chapter/Episode terbaru (misal `Ch. 179` atau `Ep. 12 • Sub`).

## 4. Fitur "Smart Cross-Link" (Komik <-> Anime) via AniList Relations
- Pada query GraphQL `anilist.enricher.ts`, tambahkan pengambilan field `relations { edges { relationType node { id title { romaji english } type format coverImage { large } } } }`.
- Di Hero Banner dan Halaman Detail:
  - Jika sedang melihat **Komik** yang memiliki relasi adaptasi `ANIME`, tampilkan tombol tambahan **`🎬 Tonton Anime`** di samping tombol `Baca` dan `Info`.
  - Jika sedang melihat **Anime** yang memiliki sumber `MANGA`, tampilkan tombol **`📖 Baca Komik`**.

## 5. Siapkan Layout Halaman Nonton Anime (`AnimeWatchPage`)
- Buat layout 2 kolom modern (Desktop: 70% Video Player di kiri + 30% Daftar Episode scrollable di kanan; Mobile: Video di atas + Daftar Episode di bawah).
- Di bawah player, sediakan bar kontrol: `Ep Sebelumnya`, `Ep Selanjutnya`, toggle `Auto-Next`, tombol `Cinema Mode (Gelapkan Layar)`, dan pemilih Server/Resolusi.
